## Title: JOB-BOARD

## Description: Job-Board project is an app that allows users to search and apply for job and also as an Employer can post a job. 
[Live Demo link](https://job-board-mitchelledev.netlify.app)  
## Features: 
• Sign up.
• sign in.
• Browse jobs.
• Apply jobs.
• Post jobs.
• (employer) Manage and Delete jobs. 
• Edit profile.
## Tech Stack: 
• React
• JAVASCRIPT
• React-Router
• Tailwind CSS
• Context API
• LocalStorage.
## How to run it locally: 
 npm install
 npm run dev
## known limitations: Data lives in the browser only, passwords are stored in plain text, and jobs don't appear for other visitors. This is a demo not production software. jobs are saved in each user's browser, so post are not shared between visitors.
